## Próximos passos para a sessão local

### 1. Instalar instaloader
```bash
cd F:\delirio-manager\projeto-raquel
pip install instaloader
```

### 2. Rodar o primeiro sync completo
```bash
python main.py sync-instagram
```
Na primeira execução vai abrir o browser para autorizar o OAuth2 do YouTube.
Selecionar o canal **Raquel Pires** e confirmar.

O sync baixa todos os vídeos do @raquelpiiires e faz upload no YouTube.
Pode demorar dependendo de quantos vídeos ela tem.

### 3. Configurar sync diário automático
Abrir o **Agendador de Tarefas do Windows** e criar tarefa:
- Disparador: diariamente às 09:00
- Ação: `F:\delirio-manager\projeto-raquel\deploy\sync_daily.bat`

Ou o Claude local pode fazer isso automaticamente via PowerShell.

## Decisões importantes

- **Projeto Raquel é independente do Delirio Manager** — chave Anthropic própria, orçamentos separados
- **Estratégia atual**: replicar vídeos do Instagram no YouTube primeiro, depois evoluir para conteúdo original gerado por Claude
- **instaloader** escolhido sobre yt-dlp porque funciona em perfis públicos sem login
- Canal YouTube na conta do André para facilitar manutenção (pode ser transferido para Raquel depois)
- OAuth2 no projeto `anatomia-do-discurso` do Google Cloud (já tinha YouTube API ativa)
