## Bugs Corrigidos

### v1.0.62 — Causa raiz: modal desmontado antes dos botões aparecerem

`onGenerated` → `onStoreListRefresh?.()` → `loadStores()` → `setLoading(true)` no `ReportModule` → desmonta `StoreDashboard` + `GenerateModal` imediatamente após geração.

**Fix em `StoreDashboard.jsx`:**
```jsx
// Antes:
onClose={() => setShowGenerate(false)}
onGenerated={() => { load(); onStoreListRefresh?.() }}

// Depois:
onClose={() => { setShowGenerate(false); load(); onStoreListRefresh?.() }}
onGenerated={() => {}}
```

**Padrão:** `onGenerated` só para efeitos locais. Recarregar pai → `onClose`.

### v1.0.61 — Modal fechava antes dos ~28s de geração

- Endpoint demora ~28s (Claude Haiku), mas botão dizia "pode levar 15s"
- `api.getServerUrl?.()` era `undefined` → URL de download ficava relativa e inválida

**Fixes em `GenerateModal.jsx`:**
- Backdrop-click e Cancelar bloqueados enquanto `generating === true`
- Mensagem: "pode levar 15s" → "aguarde até 1 min"
- `import { getServerUrl }` separadamente (não é método do objeto `api`)

### v1.0.60 — StoreList não atualizava score pós-geração

`onStoreListRefresh={loadStores}` propagado de `ReportModule` → `StoreDashboard`.
