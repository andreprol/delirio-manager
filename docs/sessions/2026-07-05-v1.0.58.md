### v1.0.58 — Bug Fixes

**Bug 1 — Botão Excluir Invisível**  
Emoji `🗑` (U+1F5D1) não tem glifo no Chromium do Electron.  
Fix: `<button style="background:#2d1f1f; color:#fc8181">✕ Excluir</button>`

**Bug 2 — Fotos Apagadas ao Editar**  
`photo_paths: undefined` omitido no JSON → servidor salvava `null` no DB.  
Fix server: `'photo_paths' in req.body` antes de atualizar.  
Fix db: `updateTopic` preserva `photo_path` quando recebe `undefined`.  
Fix response: retorna `parsePhotoPaths(topic.photo_path)` (DB, não body).

**Bug 3 — Upload EACCES (raiz do problema)**  
`mkdirSync('relatorio-photos')` cria pasta `root:root 755` quando PM2 roda como root.  
Fix: `fs.chmodSync(RELATORIO_PHOTOS_DIR, 0o777)` após `mkdirSync` em `server.js`.
