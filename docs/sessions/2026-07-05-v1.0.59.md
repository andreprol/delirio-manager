## Feature: Download de Relatório sem Dialog + Escolha de Formato

### Problema
Ao gerar o relatório, o Electron abria o dialog "Salvar como..." do Windows Explorer para cada arquivo (Word e PDF). O usuário não tinha como controlar o local de destino ou escolher apenas um formato.

### Solução

**1. Download silencioso para pasta Downloads**

`electron/main.js` — handler adicionado em `createWindow()`:
```javascript
win.webContents.session.on('will-download', (event, item) => {
  const savePath = path.join(app.getPath('downloads'), item.getFilename())
  item.setSavePath(savePath)
  item.on('done', (e, state) => {
    win.webContents.send('download-done', { state, filename: item.getFilename(), savePath })
  })
})
```

Intercepta todos os downloads via session — `item.setSavePath()` substitui o dialog por gravação direta na pasta Downloads do sistema.

IPC `download-file` + `download-done` adicionados em `main.js` e `preload.js`.

**2. Escolha de formato**

`GenerateModal.jsx` — resultado da geração exibe dois botões:
- ⬇ Word (.docx) — `background: #2b6cb0`
- ⬇ PDF — `background: #c53030`

Confirmação: "✅ Salvo na pasta Downloads: filename" após `download-done`.
