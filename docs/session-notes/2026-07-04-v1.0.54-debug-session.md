# Session Notes — 2026-07-04 — v1.0.54 Debug & Deploy

## Context

After launching v1.0.51–1.0.52 with the full Módulo Relatório (Freshdesk integration, score AI, .docx/.pdf), the user reported 4 bugs in the installed binary. This session diagnosed and fixed all of them, culminating in v1.0.54.

## Bugs Fixed

### 1. ReportModule background — monitoring panel bleeding through

**Root cause:** `background: '#0f0f19f0'` (94% opacity). The fix (`#0f0f19`) had been committed but the v1.0.52 binary was built _before_ that commit.

**Fix:** Rebuild in v1.0.54 — source already had the correct value.

**File:** `dashboard/src/components/ReportModule.jsx`

---

### 2. UpdateToast invisible / unclickable when ReportModule was open

**Root cause:** `zIndex: 9998` on UpdateToast was below ReportModule overlay `zIndex: 9999`. Same problem as #1: fix was committed but binary was stale.

**Fix:** Rebuild in v1.0.54 — `zIndex: 99999`.

**File:** `dashboard/src/components/UpdateToast.jsx`

---

### 3. freshdeskCount = 0 for all stores

**Root cause (primary):** PM2 process was started at 22:35; `relatorio.js` was updated at 23:14. PM2 was running 39-minute-old code.

**Root cause (secondary):** After multiple `pm2 restart` attempts, old cluster worker processes (ghost workers) survived and continued serving stale code. `pm2 list` showed only the new PID but `ps aux` revealed additional ghost processes.

**Failed attempts:**
- `pm2 restart dt-manager` — doesn't kill cluster ghost workers
- `pm2 restart --update-env` — same

**Fix:**
```bash
pkill -f 'node /opt/dt-manager/server.js'  # kills ALL workers including ghosts
pm2 delete dt-manager
pm2 start /opt/dt-manager/ecosystem.config.js
pm2 save
```

**File:** `server/routes/relatorio.js` — `/api/relatorio/stores` endpoint

### 4. "Assembleia" store appearing twice (duplicate)

**Root cause:** NFC/NFD Unicode mismatch.
- `machines.location` stores `Assembléia` as NFC (byte `C3 A9` = U+00E9)
- Freshdesk stores `Assembleia` (no accent)
- JavaScript `===` comparison fails → two distinct entries

**Failed attempt — LOC_ALIASES object:** `{ 'Assembléia': 'Assembleia' }` lookup returned `undefined` silently because the JS string literal encoding differed from the database NFC bytes.

**Fix — Canonical map with stripAccents:**
```javascript
const stripAccents = s => s.normalize('NFD').replace(/[̀-ͯ]/g,'').toLowerCase().trim();
const canonical = new Map();
// populate: machines (lowest priority) → topics → freshdesk (highest — overwrites)
```
Freshdesk name (`Assembleia`) wins. Result: 11 unique stores, no duplicate.

**File:** `server/routes/relatorio.js`

---

### 5. "Manutenção" store should not appear in report list

**Root cause:** Manutenção has machines in the `machines` table (location = 'Manutenção') but is not an operational store — no Freshdesk tickets, no reports.

**Fix:** Add to exclusion block alongside 'Temporário':
```javascript
storeSet.delete('Manutenção');
storeSet.delete('Manutencao');
```

**Complication:** First Python patch attempt used double quotes to find the marker but the JS file uses single quotes → patch applied silently without effect. Fixed by using single quotes in the pattern.

**File:** `server/routes/relatorio.js`

## Deploy Issues Encountered

### GitHub CDN cache
After `git push`, `curl -fsSL https://raw.githubusercontent.com/...` on the VM returned stale cached content for several minutes.

**Workaround:** Inline Python `az vm run-command` heredoc patches the file directly without fetching from GitHub.

### base64 via --scripts size limit
Attempting to base64-encode `relatorio.js` and pass via `--scripts` failed with "line too long" in PowerShell.

**Workaround:** Python heredoc `python3 << 'PYEOF' ... PYEOF` — no size limit, handles multiline.

### Single quotes in Python heredoc via --scripts
To embed single quotes in a Python string inside `--scripts`:
```bash
'"'"'value with single quotes'"'"'
# Pattern: close outer quotes → literal ' → reopen outer quotes
```

## Safe VM Deploy Pattern (definitive)


## Key Lessons

| # | Lesson | Impact if ignored |
|---|---|---|
| 1 | PM2 cluster mode leaves ghost workers after `restart` | Stale code serves traffic; deploy appears to succeed but doesn't |
| 2 | Always check when PM2 process started vs. when file was last edited | Unexplained zero-values in API responses |
| 3 | NFC/NFD mismatch breaks `===` in JS — use `stripAccents` (NFD normalize both sides) | Alias objects silently fail; duplicate store entries |
| 4 | GitHub raw CDN caches for minutes after push | VM receives old file despite successful push |
| 5 | Single-quote escaping in Python heredoc via az vm run-command `--scripts` | Patch applies silently without effect |
| 6 | Build Electron binary AFTER committing all fixes | Binary contains old bugs; requires another full rebuild (~5 min) |
